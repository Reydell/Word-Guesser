# Описание
Игра, в которой цель - отгадать слово посредством естественного разгоаора с ботом. Можно задавать вопросы, просить подсказку или делять прямые догадки. Агент сам разберется, как реагировать и куда перенаправить запрос.
# Бэкенд
FastAPI + LangGraph в основе.
# Фронтенд
Streamlit + для удобства тестирования был написан tg-бот.
